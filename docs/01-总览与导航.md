# 第 1 部分 · 产品总览与导航

> 本部分是整套餐餐的「地图」。读完它，你就知道这套东西是什么、包含哪几页、怎么进、每天怎么更新、数据从哪来。其余 4 个部分分别展开每一类报告怎么看。

## 1.1 这套产品是什么

同一套打法：**公开行情数据 + 单页 HTML + 工作日自动更新**。

- 每个报告是**一个独立 HTML 页面**，双击即可在浏览器打开，离线也能看（数据来自生成时的快照）。
- 统一皮肤：**白底、黑字、红涨**（涨=红、跌=灰，**不使用绿色**）。
- 由 GitHub Actions 在每个交易日 **16:30（北京时间）** 自动抓取 → 渲染 → 部署，无需人工干预。

## 1.4 统一视觉规范

| 项目 | 取值 |
|---|---|
| 背景 | 白 `#ffffff` |
| 正文 / 标题 | 黑 `#141414` |

圆角 2–4px，硬朗简洁；移动端自适应。所有页面的配色都来自同一份 `scripts/style.css`，改一处全站生效。

## 1.5 自动更新机制

- 触发：` .github/workflows/daily.yml` 中 `cron: '30 8 * * 1-5'`（UTC 08:30 = 北京时间 16:30，A股 15:00 收盘后）。
- 流程：**抓取 8 份数据 → 生成 8 个页面 → 校验产出（≥10KB）→ 提交 → GitHub Pages 部署**。
- 手动触发：Actions 页面点 `Run workflow`，支持填日期 `YYYYMMDD` 回补历史。
- 数据性质：所有数字都是「抓取时点」的公开市场数据快照，**不是实时逐笔**。
