# 第 5 部分 · 标的研究、打新与自动化运维（ipo.html + fund.html + 工程层）

> 本部分收尾：编号 6、8 是两个「具体标的」维度的报告，之后是整套系统的**运维与扩展指南**——给你（非程序员）也能照着做的最小操作手册。

## 5.1 新股 / 次新复盘（ipo.html）

### 看什么
近端次新（上市不久的新股）是市场情绪的「先锋指标」：
- 次新股整体强弱、近期上市表现、有没有走出连板标杆。
- 次新强 → 风险偏好高、资金愿意追高；次新崩 → 情绪退潮的早期信号。

### 怎么读
- 板块内涨停家数、平均涨幅越高 → 情绪越活跃。
- 可与第 2 部分「情绪温度」对照：次新强 + 情绪热 = 高风险偏好共振。

### 数据口径
- 来源：东财概念板（次新概念），稳定。当前为「板块强度」视角，非逐只新股申购日历。

## 5.2 基金净值 / 重仓追踪（fund.html）

### 看什么
追踪你**持有 + 关注**的基金净值与涨跌：

| 类别 | 示例 | 数据源 |
|---|---|---|
| ETF | 电子ETF(515260)、沪深300ETF(510300)、科创50(588000) 等 | 东财 ETF 行情（ulist 直查 secid），稳 |
| 开放式 | 专特新量化(015071) | 东财基金净值接口 |

### 怎么读
- ETF 行：显示最新净值 / 涨跌 / 近 1 年表现（可拨）。
- 红色为涨、灰色为跌，与全站一致。

### 数据口径
- **ETF 部分稳定**：走 `ulist` 直查 secid，返回净值 + 涨跌。
- **开放式基金（如 015071）**：净值接口（`fundgz`）在本环境被拦，页面**兜底为空**；海外日更环境通常可通，次日补齐。
- 想加自己的基金？改 `scripts/fund_fetch.py` 里的 `WATCH` 列表（见 5.4）。

## 5.3 自动化运维（给非程序员的最短手册）

### 每天自动发生什么
`16:30` GitHub Actions 自动：抓取 8 份数据 → 生成 8 个页面 → 校验 → 提交 → Pages 部署。你**什么都不用做**，第二天打开就是新的。

### 想手动跑一次（回补某天）
GitHub 仓库 → Actions → 「每日A股复盘矩阵」→ Run workflow → 可填日期 `YYYYMMDD`。

### 本地自己跑（需装 Python，纯标准库，无第三方依赖）
```bash
# 抓数据
python scripts/fetch_data.py      # 情绪页   → data.json
python scripts/flow_fetch.py      # 资金榜   → data_flow.json
python scripts/lhb_fetch.py       # 龙虎榜   → data_lhb.json（可能空）
python scripts/global_fetch.py    # 大类资产 → data_global.json
python scripts/val_fetch.py       # 估值     → data_val.json
python scripts/ipo_fetch.py       # 次新     → data_ipo.json
python scripts/bond_fetch.py      # 转债     → data_bond.json
python scripts/fund_fetch.py      # 基金     → data_fund.json

# 出页面
python scripts/render_report.py   # → sentiment.html
python scripts/flow_render.py     # → fundflow.html
python scripts/lhb_render.py      # → lhb.html
python scripts/global_render.py    # → global.html
python scripts/val_render.py      # → valuation.html
python scripts/ipo_render.py      # → ipo.html
python scripts/bond_render.py     # → bond.html
python scripts/fund_render.py     # → fund.html
```

### 加一个新报告（扩展模板）
1. 复制 `flow_fetch.py` → `xxx_fetch.py`，改数据源 URL 与字段解析，输出 `data_xxx.json`。
2. 复制 `flow_render.py` → `xxx_render.py`，改 `DP/OP` 路径与页面模板，输出 `xxx.html`。
3. 在 `daily.yml` 的「抓取」和「生成」两步各加一行，并在「校验 / git add」列表补上 `xxx.html`、`data_xxx.json`。
4. 在 `index.html`（总览页）加一张卡片指向 `xxx.html`。
5. 提交推送，次日自动纳入日更。

## 5.4 常见问题（FAQ）

| 现象 | 原因 | 处理 |
|---|---|---|
| 龙虎榜 / 基金开放式显示「数据暂缺」 | 本环境对应接口被拦 | 属正常兜底；海外日更会自动补真实数据 |
| 大类资产缺黄金/原油/美债 | 商品代码本环境限流 | 海外日更补全，页面已标注口径 |
| 估值是定性带不是精确分位 | 分位接口不稳 | 如需精确分位，后续接估值数据中心 |
| 页面数字和看盘软件差一点 | 快照时点 + 镜像延迟 | 以交易所收盘为准，本页用于复盘非实盘 |
| 配色不是白底黑字红涨 | 缓存 | 强制刷新（Ctrl+F5）或加 `?v=时间` |

## 5.5 已知限制一览（集中说明）
1. 龙虎榜、开放式基金净值：依赖数据中心接口，本沙箱被拦，线上日更补齐。
2. 大类资产：黄金/原油/美债暂缺，待补。
3. 估值：定性参考带，非实时历史分位。
4. 所有数据为收盘后快照，非实时逐笔；涨跌幅与交易所一致，净值类以数据源为准。
5. 全站不构成投资建议（见各页免责声明）。
