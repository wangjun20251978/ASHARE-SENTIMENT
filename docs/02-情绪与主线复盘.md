# 第 2 部分 · 情绪与主线复盘（sentiment.html）

> 本部分只讲「编号 0」这一页：它回答三个问题——**今天市场情绪冷还是热？谁在涨（真主线还是诱多）？明天开盘前该警惕什么？**

## 2.1 页面结构

1. **顶部 KPI 条**：涨停家数、封板率、连板高度、连板晋级率（四维核心指标）。
2. **市场广度**：沪深两市上涨 / 下跌家数（用两市指数自带涨跌家数，不重叠统计）。
3. **涨停梯队**：按连板数分层的个股清单（几连板都有谁）。
4. **情绪温度**：一个 0–10 的仪表盘，配文字档位。
5. **主线题材 / 产业主线**：概念口径 + 行业口径双视角，标注「真主线 / 疑似诱多」。
6. **延续性预警**：主线与情绪的延续 or 反转信号。

## 2.2 情绪温度算法（怎么算出来的）

四维加权，各维度按 A 股现实标尺归一化：

| 维度 | 权重 | 含义 |
|---|---|---|
| 涨停家数 | 30% | 市场赚钱效应的温度计 |
| 封板率 | 25% | 打板资金的成功率 |
| 连板高度 | 25% | 短线情绪的极致高度 |
| 连板晋级率 | 20% | 高位股续命的概率 |

**档位划分：**

| 分值 | 档位 | 直观感受 |
|---|---|---|
| 0 – 2 | 冰点 | 没人愿意追高 |
| 2 – 3.5 | 冷 | 谨慎、缩量 |
| 3.5 – 5.5 | 中性 | 正常博弈 |
| 5.5 – 7.5 | 热 | 赚钱效应扩散 |
| 7.5 – 10 | 沸腾 | 情绪逼空，注意回撤 |

## 2.3 主线识别逻辑（关键，别被假主线骗）

- **题材主线（概念口径）**：过滤掉「昨日连板 / 涨停 / 跌停 / ST / 次新 / 预增」等**情绪类伪概念**，只看真实产业题材。
- **产业主线（行业口径）**：结合板块内涨停家数，确认有资金实实在在打板。
- **扩散度** = 板块内上涨家数 ÷（上涨 + 下跌）家数，衡量主线是否「全家桶」式上涨。
- **疑似诱多**：出现「板块指数上涨，但主力资金净流出 / 内部分歧大 / 没有涨停支撑」时，标记为诱多，谨慎追。

## 2.4 怎么看这一页（实操建议）

1. 先看**情绪温度档位**：冰点/冷 → 控仓为主；热/沸腾 → 注意高潮后分歧。
2. 再看**涨停梯队高度**：连板高度突然断层（如 5 板后直接 2 板），说明高位接力断档。
3. 重点读**主线标注**：红色「真主线」可跟踪，「疑似诱多」别上头。
4. 最后看**延续性预警**：提示主线是否可能次日熄火。

## 2.5 数据口径与边界

- 数据来源：东方财富行情镜像（涨停池走 `push2ex`，其余走 `push2delay`）。
- 涨停 / 炸板 / 跌停、连板数、封板时间均来自交易所公开快照，T 日 15:00 后定型。
- 情绪温度为**框架化推演指标**，用于感受市场温度，不构成买卖依据。
- 页面含「← 返回总览」链接，便于回到总览页。
