# A股主线与情绪复盘

单文件 HTML · 双击即用 · 本机运行 · 数据不联网上传

## 这是什么

一个「**收盘后 5 分钟看懂今天**」的复盘页面，回答两个问题：

1. **今天市场在交易什么主线？**（是真主线还是诱多）
2. **情绪到了几度？**（能不能接着做）

## 页面包含

| 模块 | 内容 |
|---|---|
| 市场温度 | 五大指数涨跌、近 6 日成交额、量能趋势 |
| 板块强弱 | 行业 / 概念涨幅榜、5日 / 20日持续性对照 |
| 主线识别 | 真主线 vs 诱多做对照，附判定依据 |
| 资金流 | 行业主力净流入、重点个股「单日 + 5日」双维校验 |
| 情绪温度计 | 0–10 档位、涨停梯队（连板高度分层）、涨停归属结构 |
| 延续性预警 | 风险预警 × 3 + 支撑 × 2 |
| 隔夜判断 | 明日观察清单 6 项 + 操作含义（非投资建议） |

## 特点

- **涨红跌绿**，符合 A 股习惯
- **单文件 HTML**，无外部依赖，断网也能打开
- 手机浏览器可「添加到主屏幕」，像 App 一样用
- 所有结论区分「事实数据」与「框架推演」，不混淆

## 使用

下载 `index.html`，双击用浏览器打开即可。
