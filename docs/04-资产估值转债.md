# 第 4 部分 · 资产温度、估值与转债（global.html + valuation.html + bond.html）

> 本部分跳出 A 股本身，看「外围环境 + 宽基贵贱 + 低风险标的」三件事。编号 4 看外围冷暖，编号 5 看指数贵不贵，编号 7 看转债这个「下有保底」的品种。

## 4.1 大类资产夜盘温度计（global.html）

### 看什么
隔夜外盘对次日 A 股风险偏好有指引作用。本页给出：

- **夜盘温度计**：以美股三大指数（道指 / 标普 / 纳指）均涨为基准，计算平均值 `us_avg`，映射到「偏冷 / 中性 / 偏暖」。
- **大类资产一览表**：各资产最新价 + 涨跌幅，按类别（美股 / 亚太 / 外汇）分组。

### 怎么读
- `us_avg > 0.3` → 偏暖，外围给 A 股托底；`< -0.3` → 偏冷，注意低开。
- 关注「美元指数、黄金、原油」是否同步异动——它们往往提前反映风险偏好。

### 数据口径与缺口（透明说明）
- 来源：东方财富外盘镜像（push2delay），稳定。
- **当前已含**：道指 / 标普 / 纳指 / 美元指数 / 恒生 / 日经。
- **暂缺项**：黄金、原油、美债。原因——这些商品代码在本环境历史请求中被限流，未能解出；**将在海外日更环境补全**。页面已标注此口径，不是数据错误。

## 4.2 指数估值分位看板（valuation.html）

### 看什么
主要宽基指数的**点位、当日涨跌幅、定性估值带**：

| 字段 | 含义 |
|---|---|
| 指数 | 上证 / 沪深300 / 创业板 / 中证500 / 科创50 / 上证50 / 中证1000 / 深证成指 |
| 点位 | 最新收盘 |
| 涨跌幅 | 当日真实变动 |
| PE 参考区间 | 给该指数一个粗略的 PE 低/高档（定性参考） |
| 估值带 | 合理偏低 / 合理 / 偏高 等定性结论 |

### 怎么读
- 涨跌幅是**每日真实更新**的，可直接看强弱。
- 估值带用于判断「相对贵贱」：**合理偏低 + 跌** → 接近配置区；**偏高 + 涨** → 注意拥挤。

### 重要声明（避免误读）
- **估值带是定性参考，不是精确历史分位**。实时 PE/PB 历史分位接口在本环境不稳定，故以「近期 PE 参考区间 + 定性结论」呈现。
- 如需精确分位（如「当前 PE 处于过去 10 年 30% 分位」），需后续接入估值数据中心——属可扩展项，非当前数据。

## 4.3 转债市场温度计（bond.html）

### 看什么
可转债是「债底保护 + 股性弹性」的标的，适合低风险偏好：

- **转债等权指数 / 平均溢价率**：衡量整体冷热。
- **双低池**：「价格低 + 溢价率低」的可转债，攻守兼备，经典摊大饼策略的选池。
- **涨幅榜**：当日 active 的转债。

### 怎么读
- 平均溢价率**过高** → 转债整体偏贵，债底保护变薄。
- 双低值越小 → 越「便宜又跟涨」，但需结合正股质地排雷（避免踩雷违约）。
- 本页数据来自东财可转债接口，稳定。

## 4.4 三页关联
`global`（外围冷暖）→ 影响 `valuation`（宽基强弱背景）→ 风险偏好低时 `bond`（转债）提供「进可攻退可守」的备选。三页底部均有「← 返回总览」。
