# 第 3 部分 · 资金面：主力资金榜与龙虎榜（fundflow.html + lhb.html）

> 本部分讲「钱往哪去」。编号 2 看**板块/个股主力净流入的方向**，编号 3 看**顶级游资与机构席位的买卖动作**。两者合起来 = 资金的「大势」与「高手」。

## 3.1 主力资金净流入榜（fundflow.html）

### 看什么
- **行业净流入榜 Top**：今天主力真金白银加仓了哪些行业。
- **概念净流入榜 Top**：题材层面的资金偏好（如某概念集体吸金）。
- **个股净流入榜 / 净流出榜**：单只股票的主动买卖净额（单位：元，页面换算为「亿」）。

### 怎么读
- **净流入 = 主动买入 − 主动卖出**（大单口径）。红色为正、灰色为负。
- 行业 + 概念「双榜同热」的板块，往往就是当天主线（可与第 2 部分主线交叉验证）。
- 个股净流出榜前列、但价格还在涨 → 可能是拉高出货，警惕。

### 数据口径
- 来源：东方财富板块 + 个股资金流（push2delay 镜像），稳定。
- `f62` 为主力净流入额，`f184` 为主力净流入占比（占成交额比例），占比比绝对额更能看出「力度」。

## 3.2 龙虎榜席位动向（lhb.html）

### 看什么
龙虎榜 = 当天**异动股**（涨停/跌停/大幅换手/异动）的买卖席位明细。本页展示：

| 字段 | 含义 |
|---|---|
| 名称 / 代码 | 上榜证券 |
| 交易日期 | 上榜日 |
| 解读（EXPLAIN） | 上榜原因（如「日涨幅偏离值达 7%」） |
| 收盘价 / 涨跌幅 | 当日表现 |
| 龙虎榜净买额 | 上榜席位买卖净额 |
| 买入额 / 卖出额 | 席位的主动买 / 卖总量 |
| 成交额 / 换手率 | 全天活跃度 |
| 上榜原因 | 触发异动的条件 |

### 怎么读
- **净买额为正且大** → 席位整体看多，游资/机构合力。
- 结合「机构专用」与知名游资席位，可观察**主力风格切换**（机构趋势 vs 游资连板）。
- 连续多日上榜同一只 → 资金在反复博弈，关注持续性。

### 重要边界（务必知道）
- **数据源**：东方财富**数据中心**（`datacenter.eastmoney.com`）接口。
- **本沙箱环境出口被拦截**：在本地/当前环境抓取时会失败，页面**兜底显示「数据暂缺」**，不会报错崩溃。
- **日更运行于海外服务器**：该接口通常可正常获取，第二天 16:30 自动补真实榜单。
- 所以：在自动化日更的线上版本里，龙虎榜是**真实数据**；本地临时跑可能为空——属正常兜底，不是 bug。

## 3.3 两页的关联
资金榜（大势方向）+ 龙虎榜（高手动作）= 完整资金视图。建议：先用 `fundflow` 锁定「今天钱去了哪个行业」，再用 `lhb` 看「具体是哪路资金在干」。两页底部均有「← 返回总览」。
